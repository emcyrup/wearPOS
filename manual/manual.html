1

はじめに（画面を開く・ログイン）

ブラウザで次の URL を開きます。よく使う端末では、ブックマークやホーム画面に追加しておくと便利です。

https://wearpos.ai-labo.cloud

ログインする

  1. 自分の名前を選ぶ
    ユーザー名は一覧から選ぶだけです
  2. パスワードを入力して ログイン
自分のユーザーがまだ無いときは、店長（管理者）に作ってもらってください。お店の設定によっては、ログイン画面の 新規ユーザーを作成 タブから自分で作れることもあります（合言葉が必要な場合があります）。
パスワードを続けて 8 回間違えると、そのユーザーは 15 分間ログインできなくなります。あわてず時間をおくか、店長に連絡してください。

レジ端末をはじめて使うとき

店頭のレジ端末は、ログインなしでレジ画面を開けるようにできます。そのかわり、最初に一度だけ「レジ端末コード」の入力が必要です。

  1. レジ画面を開くと、コードの入力欄が出る
  2. 店長から聞いたレジ端末コードを入力して この端末で使えるようにする
  3. 以降 90 日間は、その端末はコードなしでレジを使えます
    別の端末を使うときは、その端末でも一度入力してください。
ログイン済みであれば、コードを入れなくてもレジは使えます。コードは「店頭のタブレットをログインなしで使う」ための仕組みです。

権限について

  • 管理者: すべての操作（商品登録・価格変更・顧客情報・設定など）
  • スタッフ: 許可された画面のみ（レジ・商品・在庫など。権限は管理者が決めます）
  • 使いたい画面が見えないときは、権限の追加を店長に相談してください
  • パスワードを忘れたら管理者に連絡してください（リセットできます）
2

会計する（レジ）

サイドメニューの レジ ↗ を押すと、レジ専用ウィンドウが開きます。

  1. 担当スタッフを選ぶ （必須）
    自分の名札バーコードを 📷 読み取る でスキャンしてもOK。選ばないと会計ボタンが押せません。
  2. 商品を追加する
    値札のバーコードをスキャン（カメラ／ハンドスキャナ）。読み取れないときは 🔍 商品名で検索。値札が無いもの（ノベルティ等）は ✏️ 未登録商品を手入力 で商品名と価格を入力します。
  3. 会員をつける（任意）
    お客様の LINE 会員証バーコードをスキャン、または会員番号を入力して 照会。分からないときは 🔍 お名前・電話番号で検索。
  4. 値引き・ポイントを使う（任意）
    1商品だけなら その行の「この明細を値引き」、会計全体なら「伝票値引き」。¥ と % の両方を入れると合算されます。会員のポイントもここで使えます。
  5. 支払方法を選ぶ
    現金は お預かり金額を入力するとお釣りが自動計算されます。クレジット等は、決済端末での処理が終わったことを確認してから進めます。
  6. 会計する を押す
  7. レシートを印刷 → 別ウィンドウで開くので印刷して閉じる
  8. 次の会計へ で次のお客様へ
在庫の減算・ポイントの付与・累計購入額と会員ランクの更新・お客様への LINE 通知まで、会計と同時に自動で行われます。

承認番号を残す（決済メモ）

クレジットや QR 決済など、別の端末で処理した支払いは、決済端末の承認番号・伝票番号をメモとして残せます。

  • 支払方法を選ぶと、その下にメモ欄が出ます
  • 入力した番号は伝票詳細に「No. ○○」と表示されます
  • あとで決済端末の控えと突き合わせるときに役立ちます
3

支払いを分けて受け取る

「現金 1万円 ＋ 残りを電子マネー」のように、1 回の会計で支払方法を組み合わせられます。

  1. お会計の欄で 支払方法を分けて支払う を押す
  2. 使う支払方法のボタンを押す
    押すと残額が自動で入ります。金額を直せば、残りは次の行に回せます。
  3. 現金の行は お預かり金額 を入れる
    行ごとにお釣りが計算され、合計のお釣りも表示されます。
  4. 内訳の合計がお支払い額とぴったり合ったら 会計する
    ぴったり合うまで会計ボタンは押せません。残額は画面に表示されています。
分割に使えるのは、店長が設定で「分割決済に使える」にした支払方法だけです。ボタンが出ないときは店長に確認してください。
レシートと伝票詳細には、支払方法ごとの内訳が印字・表示されます。返品したときも、この内訳どおりに返金されます。
4

返品する（会計の取り消し）

レジの打ち間違い・お客様都合の返品はこちら。むずかしい操作はありません。

  1. 取引履歴 から対象の伝票を探して開く
    伝票番号や会員名で絞り込みできます。行をクリックすると詳細が開きます。
  2. 右上の 返品する を押す
  3. 返す商品の点数を決める
    はじめは全部が選ばれています。− ＋ で点数を変えれば、1点だけ返すこともできます。
  4. 返金の方法を選ぶ
    そのままなら元の支払い方法どおりに返します。クレジットの取消ができないときなどは「返金方法を指定する」で現金に振り替えられます。
  5. 右下の ○ 点を返品する を押して、確認画面で OK

返品したぶんだけ自動で元に戻るもの

  • 商品の在庫（戻し入れ）
  • お客様が使ったポイント（返還）・付いたポイント（取消）
  • 累計購入額・会員ランク（来店回数は、伝票を全部返品したときだけ 1 減ります）
一部だけ返品したときは、残りをあとから返品できます。伝票には「一部返品」と表示され、明細ごとに返した点数が出ます。同じ商品を二重に返品することはできません。
5

商品を登録する

管理者の操作です。商品 / SKU → 商品を登録 から行います。

  1. 商品名・価格を入力
    必ず入れるのは 商品名・プロパー価格・サイズ の3つだけです。
  2. 品番は空欄でかまいません
    空なら自動で採番されます（例: P2609-001）。
  3. サイズを選ぶ（カラーは任意）
    選んだ組み合わせぶんの SKU（在庫の管理単位）が自動で作られます。カラー展開のない小物などはカラーを選ばなくてよく、その場合は「指定なし」1つになります。
  4. JAN コードは自動採番
    採番年月は数字6桁で入力します（例: 202609）。
  5. 登録後、値札ラベルを印刷 でバーコード付きの値札を印刷

メーカーの値札をそのまま使う（値札の付け替え不要）

バーコードの欄で 「既存のバーコードを読み取って登録する」 を選ぶと、SKU ごとの読み取り欄が出ます。

  • 📷 まとめて読み取る を押すとカメラが開いたままになり、値札を1枚ずつかざすだけで上から順に入ります（次に読む SKU が画面に出ます）
  • 同じ値札を続けて読んでしまっても、二度入ることはありません
  • USB / Bluetooth のバーコードリーダーは、入力欄を選んでそのまま読み取れば 次の空欄へ自動で移ります
  • 同じバーコードを2つの SKU に入れてしまったときは、その場で赤く警告が出ます
  • 空欄のままにした SKU は、あとから商品詳細の SKU 一覧で登録できます
SKU ごとの読み取り欄は、サイズを選んだあとに出ます（品番とカラーは決まっていなくても大丈夫です）。

あとから直すとき

  • 商品の情報 → 商品詳細の 商品情報カード右上 の ✏️ 編集する（販売価格の変更は履歴に残ります）
  • SKU コード・バーコード → SKU 一覧の ✎ から変更（管理者のみ）

たくさんの商品をまとめて登録する（CSV 一括取込）

仕入先から JAN 付きの商品リスト（Excel / CSV）をもらっているときは、1件ずつ登録しなくて済みます。

  1. 商品 / SKU → CSV 一括取込
  2. ファイルを選ぶか、Excel からコピーして貼り付け
    見本を入れる を押すと、書き方の例が入ります。
  3. 内容を確認する で結果を見る
    新規・更新・エラーの件数と、1行ずつの内容が出ます。エラーが1件でもあると取り込めません。
  4. 問題なければ ○ 件を取り込む
  • 必要な列は 商品名・上代・サイズ の3つだけ。品番・カラー・JAN・在庫数・販売価格などは任意です
  • 品番が無いときは自動で採番し、同じ商品名の行をまとめて1商品にします（同じファイルを二度取り込むと二重になるのでご注意ください）
  • カラーが無いときは「指定なし」として登録します
  • 同じ品番の行はまとめて 1商品になり、カラー×サイズごとの SKU が作られます
  • 同じ JAN が二重に登録されそうなときは、取込前にエラーとして教えます
既にある商品は、既定では変更しません（JAN が空のところにだけ JAN を入れます）。上書きしたいときは設定のチェックを入れてください。
6

在庫の作業

在庫 画面で行います。一覧のラジオボタンで商品を選ぶと、その SKU がフォームに自動で入ります。

やりたいこと操作
入荷区分「入荷」＋ SKU（スキャン可）＋ 数量 → 登録する
数が合わないとき区分「在庫調整」で差分を入力（マイナスも入力できます）
棚卸区分「棚卸」で実際に数えた数を入力（その数に上書きされます）
すべての増減は「直近の在庫変動」に履歴として残ります。あとから誰がいつ変えたか確認できます。
在庫が少なくなった商品は、在庫画面の上部にアラートとして出ます（発注点は商品ごとに設定できます）。
7

お客様の登録・LINE

やりたいこと操作
店頭で新規登録顧客 (CRM) → 顧客を登録（会員番号は自動発行）
LINE で自己登録お客様が公式 LINE を友だち追加 → リッチメニューの「会員登録」から
LINE 会員証お客様がリッチメニューの「会員証」でバーコード表示 → レジでスキャン
既存会員を LINE とつなぐ顧客詳細 → 連携コードを発行（6桁）→ お客様が LINE に送る
一斉配信顧客一覧 → LINE 一斉配信
登録でお聞きする項目は、お店の設定で変えられます（お名前だけ、ニックネーム可、住所は市区町村まで、など）。画面に出ていない項目は「集めない」設定になっています。
お客様は LINE のトークに「通知オフ」「通知オン」「連携解除」と送ると、自分で設定を変えられます。
8

売上を見る・AI に相談する

  • ダッシュボード: 期間を選んで売上・客数・客単価・売れ筋などを確認できます
  • AI考察: 討論を開始 を押すと、2つの AI が実績を分析して
    【考察】（結論と打ち手）と 【提案】（次に試すこと）を出します
  • そのまま追加の質問もできます（例:「客単価を上げるには何から手を付けるべき？」）
  • お客様の個人情報は AI に送っていません。送っているのは売上などの集計値と、 会員数・リピート率といった統計だけです（氏名・電話番号・メール・住所・個別の購入履歴は送りません。 スタッフ名も「スタッフA」等に置き換えて送ります）
  • 🔍 AIに送るデータを見る を押すと、送っている内容をその場で全部確認できます
ChatGPT への送信を止めたいときは、設定 → 「AI考察と個人情報の取り扱い」でチェックを外してください。AI がつながらないときは、同じ画面の AI接続テスト で原因を確認できます。
9

店長・管理者の設定

サイドメニューの 設定 / 連携 から行います。開店前に一度確認しておくとスムーズです。

やりたいこと場所とポイント
店舗名を決める 設定 → 店舗。ここで入れた店舗名がレシートの一番上に印字されます。開店前に自店の名前へ変更してください
レジ端末コード 設定 → レジ端末のアクセス。店頭端末をログインなしで使うための合言葉です。決めたら店頭の端末で1回入力します（未設定なら、ログインした人だけがレジを使えます）
スタッフを増やす 設定 → スタッフ（レジの担当者一覧）と ユーザーと権限（ログインする人）。名札バーコードは「名札バーコード」から印刷できます
支払方法を増やす 設定 → レジの支払方法。ギフト券・商品券などを追加できます。「分割決済に使える」「お釣りを出せる」もここで決めます
新規ユーザー作成の可否 設定 → ログイン画面での新規ユーザー作成。既定は「作成させない」。スタッフを迎えるときだけ開くのがおすすめです
LINE リマインド 設定 → リマインド設定。購入後フォロー・再来店・休眠・誕生日の ON/OFF と日数を変えられます（毎日 10:00 に自動配信）
顧客登録の項目 設定 → 顧客登録の項目。集める情報を必要最小限にできます（「最小構成にする」ボタンで一括変更）
データの初期化は、テスト後に中身を空にするための機能です。既定ではボタンがグレーアウトしていて押せません。実際の運用が始まったら使わないでください。
10

困ったときは

症状対処
バーコードが読めないレジの 🔍 商品名で検索 から追加。値札が無いものは ✏️ 未登録商品を手入力
会計を間違えた取引履歴から伝票を開いて 返品する → 正しい内容でもう一度会計
会員が見つからないレジの「お名前・電話番号で検索」。それでも無ければ新規登録
会計ボタンが押せない担当スタッフが未選択／現金のお預かり金額が不足／分割の内訳がお支払い額と合っていない、のいずれかです
「担当スタッフを選んでください」と出るレジ画面の担当スタッフ欄が「未指定」のままです。名前を選んでください
「店舗が設定されていません」と出る店長に連絡してください（設定 → 店舗 を開いて保存すると直ります）
レジでコードを聞かれたその端末での初回です。店長からレジ端末コードを聞いて入力してください（1章）
ログインが一時的に止まったパスワードを 8 回続けて間違えると 15 分止まります。時間をおくか店長に連絡を
ポイント残高がおかしい顧客詳細のポイント履歴で増減を確認（返品分は自動で調整されています）
パスワードを忘れた管理者に連絡（設定 → ユーザーと権限 からリセットできます）
画面が固まった・表示が古いブラウザの再読み込み（スマホは画面を下に引っ張る）。会計済みのデータが消えることはありません
このマニュアルに載っていない操作や詳しい説明は、「wearPOS 機能・運用ガイド」をご覧ください。
