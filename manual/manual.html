1

ログインする

  1. wearPOS の URL をブラウザで開く
  2. 自分の名前を選ぶ
    ユーザー名は一覧から選ぶだけです
  3. パスワードを入力して ログイン
レジ画面だけはログインなしで使えます（店頭のレジ端末用）。

権限について

  • 管理者: すべての操作（商品登録・価格変更・顧客削除・設定など）
  • スタッフ: 許可された画面のみ（レジ・商品・在庫など。権限は管理者が設定します）
  • パスワードを忘れたら管理者に連絡してください（リセットできます）
2

会計する（レジ）

サイドメニューの レジ ↗ を押すと、レジ専用ウィンドウが開きます。

  1. 担当スタッフを選ぶ （必須）
    自分の名札バーコードを 📷 読み取る でスキャンしてもOK。選ばないと会計ボタンが押せません。
  2. 商品を追加する
    値札のバーコードをスキャン（カメラ or ハンドスキャナ）。読み取れないときは 🔍 商品名で検索、値札がない商品（ノベルティ等）は ✏️ 未登録商品を手入力 で商品名と価格を入力します。
  3. 会員をつける（任意）
    お客様の LINE 会員証バーコードをスキャン、または会員番号を入力して 照会。分からないときは 🔍 お名前・電話番号で検索。
  4. 値引きする（任意）
    1商品だけ → その行の「この明細を値引き」／会計全体 → 「伝票値引き」。¥ と % は両方入れると合算されます。
  5. 支払方法を選ぶ
    現金 → お預かり金額を入力（お釣りは自動計算）。クレジット等 → 決済端末での処理が終わったことを確認して確定します。
  6. 会計する を押す
  7. レシートを印刷 → 印刷して閉じる
    レシートは別ウィンドウで開きます。印刷が終わったら「閉じる」で戻ります。
  8. 次の会計へ で次のお客様へ
会計すると、在庫の減算・ポイント付与・お客様への LINE 通知まで自動で行われます。
3

返品する（会計の取り消し）

レジの打ち間違い・お客様都合の返品はこちら。むずかしい操作はありません。

  1. 取引履歴 から対象の伝票を探して開く
    伝票番号や会員名で絞り込みできます。行をクリックすると詳細が開きます。
  2. 右上の 返品する を押して、確認画面で OK

自動で元に戻るもの

  • 商品の在庫（戻し入れ）
  • お客様が使ったポイント（返還）・付いたポイント（取消）
  • 累計購入額・会員ランク・来店回数
返品済みの伝票には「返品済み」と表示され、二重に返品することはできません。
一部の商品だけの返品は現在準備中です。当面は全体を返品してから、残す商品をもう一度会計してください。
4

商品を登録する（管理者）

  1. 商品 / SKU → 商品を登録
  2. 品番・商品名・価格などを入力
  3. カラーとサイズを選ぶ
    選んだ組み合わせぶんの SKU（在庫の管理単位）が自動で作られます。
  4. JAN コードは自動採番
    採番年月は数字6桁で入力します（例: 202608）。
  5. 登録後、値札ラベルを印刷 でバーコード付きの値札を印刷

あとから直すとき

  • 商品の情報 → 商品詳細の 商品情報カード右上 の ✏️ 編集する（販売価格の変更は履歴に残ります）
  • SKU コード → SKU 一覧の ✎ から変更（管理者のみ）
5

在庫の作業

在庫 画面で行います。一覧のラジオボタンで商品を選ぶと、その SKU がフォームに自動で入ります。

やりたいこと操作
入荷区分「入荷」＋ SKU（スキャン可）＋ 数量 → 登録する
数が合わないとき区分「在庫調整」で差分を入力（マイナスも入力できます）
棚卸区分「棚卸」で実際に数えた数を入力（その数に上書きされます）
すべての増減は「直近の在庫変動」に履歴として残ります。あとから誰がいつ変えたか確認できます。
6

お客様の登録・LINE

やりたいこと操作
店頭で新規登録顧客 (CRM) → 顧客を登録（会員番号は自動発行）
LINE で自己登録お客様が公式 LINE を友だち追加 → リッチメニューの「会員登録」から
LINE 会員証お客様がリッチメニューの「会員証」でバーコード表示 → レジでスキャン
一斉配信顧客一覧 → LINE 一斉配信
お客様は LINE のトークに「通知オフ」「通知オン」「連携解除」と送ると、自分で設定を変えられます。
7

売上を見る・AI に相談する

  • ダッシュボード: 期間を選んで売上・客数・客単価・売れ筋などを確認できます
  • AI考察: 討論を開始 を押すと、2つの AI が実績を分析して
    【考察】（結論と打ち手）と 【提案】（次に試すこと）を出します
  • そのまま追加の質問もできます（例:「客単価を上げるには何から手を付けるべき？」）
8

困ったときは

症状対処
バーコードが読めないレジの 🔍 商品名で検索 から追加。値札が無いものは ✏️ 未登録商品を手入力
会計を間違えた取引履歴から伝票を開いて 返品する → 正しい内容でもう一度会計
会員が見つからないレジの「お名前・電話番号で検索」。それでも無ければ新規登録
会計ボタンが押せない担当スタッフが未選択、または現金のお預かり金額が不足していないか確認
ポイント残高がおかしい顧客詳細のポイント履歴で増減を確認（返品分は自動で調整されています）
パスワードを忘れた管理者に連絡（設定 → ユーザーと権限 からリセットできます）
このマニュアルに載っていない操作や詳しい説明は、「wearPOS 機能・運用ガイド」をご覧ください。
